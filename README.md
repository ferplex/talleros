TALLER·OS v1.3 - Windows
==========================

Pago único: $4 USD.
Licencia: 1 computadora del comprador.
Sin mensualidades. Datos 100% locales.

INSTALACIÓN RÁPIDA (3 PASOS)
-----------------------------
1) Instala TALLEROS-Setup-1.3.0.exe (doble clic).
   Si Windows muestra ventana azul: "Más información" → "Ejecutar de todas formas".

2) Ejecuta INSTALAR.bat con doble clic.
   Esto descargará e instalará Ollama y el modelo de IA automáticamente.
   (Si te pide reiniciar, hazlo y luego ejecuta INSTALAR_MODELO.bat)

3) Abre TALLER·OS desde el escritorio. ¡Listo!

VOZ Y MICRÓFONO
---------------
- El programa lee las respuestas en voz alta con las voces de Windows.
- Para hablar con el micrófono, abre "talleros-voz.html" con Edge o Chrome.

MODELOS DISPONIBLES
-------------------
- INSTALAR.bat: modelo liviano (1.5 GB, para PCs con 8 GB de RAM)
- INSTALAR_MODELO_COMPLETO.bat: modelo completo (4.4 GB, para PCs con 16 GB)

SOLUCIÓN DE PROBLEMAS
---------------------
- "Ollama sin conexión": reinicia tu PC después de instalar.
- El primer mensaje tarda unos segundos: el modelo se carga en memoria.

DATOS
-----
- Todo se guarda en tu computadora, no en internet.
- Usa "Copia JSON" para respaldar y "Importar" para restaurar.

Esta copia se entrega lista para usar.
No requiere activación ni códigos.

REQUISITOS DEL SISTEMA
----------------------
MÍNIMOS (modelo liviano qwen2.5:3b):
- Windows 10 de 64 bits
- Procesador de 2 núcleos (Core i3 / Ryzen 3)
- 4 GB de RAM
- 3 GB de espacio libre
- Internet solo para instalar

ÓPTIMOS (modelo completo qwen2):
- Windows 10/11 de 64 bits
- Procesador de 4+ núcleos (Core i5 / Ryzen 5)
- 16 GB de RAM
- 10 GB libres en SSD
- Opcional: tarjeta NVIDIA con 4 GB o más
- Internet solo para instalar
